LOTFI Portfolio — راهنمای اجرا

ساختار پروژه:
- index.html
- assets/css/styles.css
- assets/js/main.js
- assets/favicon.svg

اجرای سریع:
1) فایل ZIP را Extract کنید.
2) وارد پوشه LOTFI-Portfolio شوید.
3) روی index.html دوبار کلیک کنید تا در مرورگر باز شود.

روش پیشنهادی برای توسعه:
1) Visual Studio Code را نصب و پوشه LOTFI-Portfolio را باز کنید.
2) افزونه Live Server را نصب کنید.
3) روی index.html راست‌کلیک و Open with Live Server را انتخاب کنید.

قبل از انتشار:
- داخل index.html لینک‌های نمونه مثل @lotfi، hi@lotfi.dev و پروفایل‌های شبکه اجتماعی را با اطلاعات واقعی خودتان جایگزین کنید.
- داخل assets/js/main.js مقدار CONTACT_EMAIL را با ایمیل واقعی عوض کنید.
- آدرس canonical در HTML به #home تغییر داده شده؛ بعد از خرید دامنه، آن را با آدرس واقعی سایت جایگزین کنید.
- فرم تماس در نسخه استاتیک، برنامه ایمیل کاربر را باز می‌کند و خودش پیام را روی سرور ذخیره یا ارسال نمی‌کند. برای ارسال مستقیم، به بک‌اند یا سرویس فرم نیاز است.
- نمونه‌کارهای فعلی با برچسب «پروژه نمایشی» مشخص شده‌اند؛ آن‌ها را با پروژه‌های واقعی خودتان جایگزین کنید.

نکته:
برای بارگذاری فونت‌های Vazirmatn و Space Grotesk به اینترنت نیاز است؛ در حالت آفلاین فونت جایگزین سیستم استفاده می‌شود.
